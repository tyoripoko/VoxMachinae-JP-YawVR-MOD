#
# SCENE|シーン名|トリガーサウンド|持続秒数
#   トリガーサウンドが再生された瞬間にタイマーが0秒から起動
#
# CRADLE（旧）|シーン名|振幅|周期|Pitch位相|Roll位相|Yaw位相
# CRADLE（新）|シーン名|PitchAmp|RollAmp|YawAmp|周期|Pitch位相|Roll位相|Yaw位相
#   各軸の振幅を個別に設定可能。0.0=その軸を無効化
#   ch1-3（Pitch/Roll/Yaw）にsin波の揺り籠モーションを追加
#   位相をずらすことで各軸が異なるタイミングで揺れる
#
# VIB|シーン名|開始秒|終了秒|振幅(0-100)|Hz
#   Damage_Pitch/Roll/Yaw (ch5-7) にsin波の微振動を追加
#   複数行記述で複数ウィンドウ指定可能
#   出撃カットシーンの微振動と同じ感覚で設定
#
# DISABLE|シーン名|1
#   1=カットシーン終了後、Weapon_Vib と Damage 以外の
#     全チャンネルをステージ終了まで無効化（無重力ステージ用）
#
# ※ コメント行は行頭に # を付ける
# ※ 設定変更後はゲーム再起動が必要
# ════════════════════════════════════════════════════════════

# Gas and Go（宇宙小惑星ステージ・Drillロボット）
# トリガー: ShuttleEngine_Loop（BlastShieldOpen直後に発火）
# 持続: 107秒（FootStepResonance着地まで）
# ════════════════════════════════════════════════════════════
SCENE|GAS_AND_GO|ShuttleEngine_Loop|107
# ステージ識別: AMB_Play2D_Asteroid が鳴ったステージ（Gas and Go）のみ有効
STAGE|GAS_AND_GO|AMB_Play2D_Asteroid

# 揺り籠モーション（シャトル航行中の慣性）
# 振幅0.15 / 周期8秒 / Pitch-Roll-Yaw を120度ずつ位相オフセット
# 揺り籠モーション（宇宙空間を漂うイメージ）
# 新フォーマット: CRADLE|シーン名|PitchAmp|RollAmp|YawAmp|周期|Pitch位相|Roll位相|Yaw位相
# YawAmp=0.0 → Yawはコックピット向きと同期しているため揺り籠から除外
# 揺り籠モーション（大型船に乗っているような非常にゆっくりとした揺れ）
# 全周期6秒 = 3秒かけて右端→左端
# RollAmp=0.9: ほぼ最大まで傾く / PitchAmp=0.25: 前後の穏やかな揺れ
# YawAmp=0.0: Yawはコックピット向きと同期のため除外
# Pitch位相=90: Rollより90度ずらしてより自然な船の揺れに
CRADLE|GAS_AND_GO|0.25|0.9|0.0|18.0|90|0|0

# 微振動ウィンドウ（コクピット揺れに同期）
